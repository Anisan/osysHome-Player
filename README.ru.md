# Player - Модуль аудиоплеера

![Player Icon](static/Player.png)

Система воспроизведения аудио для воспроизведения звуковых файлов и уведомлений с управлением громкостью и очередью.

## Описание

Модуль `Player` предоставляет возможности воспроизведения аудио для платформы osysHome. Он позволяет воспроизводить звуковые файлы, управлять очередью воспроизведения и контролировать уровни громкости. Поддерживает несколько бэкендов для разных платформ.

## Основные возможности

- ✅ **Воспроизведение аудио**: Воспроизведение аудио файлов через различные бэкенды
- ✅ **Управление очередью**: Очередь нескольких аудио файлов
- ✅ **Управление громкостью**: Громкость считывается из системного свойства в реальном времени
- ✅ **Фильтрация уровня**: Фильтрация воспроизведения по минимальному уровню
- ✅ **Мульти-бэкенд**: WinMedia (Windows), PulseAudio/GStreamer (Linux), VLC, FFplay, пользовательская команда
- ✅ **Автоопределение**: Автоматический выбор бэкенда на основе платформы
- ✅ **Без транскодирования**: Воспроизведение любых форматов, поддерживаемых нативным бэкендом
- ✅ **Многопоточность**: Фоновый поток воспроизведения

## Панель администратора

Модуль предоставляет административный интерфейс для:

- **Выбор бэкенда**: Выбор аудио бэкенда (auto, winmedia, pulseaudio, gstreamer, vlc, ffplay, command)
- **Источник громкости**: Выбор связанного объекта + свойства для управления громкостью (шкала 0-100)
- **Источник мин. уровня**: Выбор связанного объекта + свойства для фильтрации по минимальному уровню
- **Пользовательская команда**: Настройка шаблона команды с плейсхолдерами `{file}` и `{volume}`

### Доступные бэкенды

| Бэкенд | Платформа | Описание |
|--------|-----------|----------|
| WinMedia | Windows | COM-интерфейс Windows Media Player |
| PulseAudio | Linux | Утилита `paplay` PulseAudio |
| GStreamer | Linux | Утилита `gst-play-1.0` GStreamer |
| VLC | Кроссплатформенный | VLC Media Player (python-vlc) |
| FFplay | Кроссплатформенный | Утилита `ffplay` из FFmpeg |
| Command | Кроссплатформенный | Пользовательская команда |

**Приоритет автоопределения:** Windows: WinMedia → VLC → FFplay → Command; Linux: GStreamer → PulseAudio → VLC → FFplay → Command.

## Использование

### Воспроизведение звука

Используйте действие `playsound`:
```python
callPluginFunction("Player", "playSound", {
    "file_name": "path/to/sound.mp3",
    "level": 5
})
```

### Управление громкостью

Громкость считывается из связанного системного свойства (0–100, нормализуется в 0.0–1.0 внутренне). Масштабирование под конкретный бэкенд применяется автоматически.

### Фильтрация по уровню

Установите порог минимального уровня через связанное свойство. Воспроизведение подавляется, когда параметр `level` ниже порога.

## Технические детали

- **Бэкенды**: Ленивые импорты — нет ошибок при отсутствии библиотек
- **Громкость**: Чтение из свойства в реальном времени при каждом воспроизведении
- **Очередь**: Потокобезопасная `queue.Queue` для аудио файлов
- **Многопоточность**: Фоновый поток воспроизведения (daemon)
- **Поддержка форматов**: Все форматы, поддерживаемые выбранным бэкендом
